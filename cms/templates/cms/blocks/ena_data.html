{% comment %} EnaDataBlock's template: a search form whose body (data type tabs, facets and results) is lazy-loaded via HTMX, then swapped whenever the search, a facet, a tab, a sort or a page changes. The search box sits outside the swapped body so typing isn't interrupted; facet checkboxes keep stable ids, so HTMX restores their focus. The current query string is passed on, so shared or bookmarked URLs load that same view. {% endcomment %}
