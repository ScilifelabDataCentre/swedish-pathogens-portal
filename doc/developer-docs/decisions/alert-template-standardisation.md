# Alert template standardisation

**Decision to be made:** How to present alerts / “last updated” messaging consistently (especially on dashboards)?

**Logic:** Mixed alert layouts confuse users. One standard alert style should be reused; other UI elements should not imitate it.

**Status:** decision

**Decision:** Use a **standardised alert style** for alerts. Do not reuse that style for unrelated elements.
