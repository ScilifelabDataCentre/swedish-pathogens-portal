# Unified development environment (uv)

**Decision to be made:** Should the team standardise on a tool for consistent Python environments?

**Logic:** Matching environments makes reviewing and testing each other’s changes easier.

**Status:** decision

**Decision:** Use **uv** for Python dependency and environment management.
