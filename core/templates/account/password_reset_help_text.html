{% comment %} This template is used to override django allauth's password reset help text template. We wanna keep this empty so that the default help text is not displayed on the login page. We use wagtail login template for django allauth login page to keep the UI consistent with the rest of the wagtail admin interface, and the wagtail template tag `formattedfield` used in the template displays the password help text (i.e. password reset link) between the label and the input field. Which doesn't look good in our case, so we disable it here by keeping this template empty and manually adding the password reset link in the wagtail login template to a more nicer location. {% endcomment %}
